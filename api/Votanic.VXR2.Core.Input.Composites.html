Table of Contents

Namespace Votanic.VXR2.Core.Input.Composites

Classes

Axis1DComposite

1D axis composite — combines two boolean bindings (positive/negative) into a single float axis value.

Axis2DComposite

2D axis composite — combines two float axis bindings (x/y) into a UnityEngine.Vector2. Analog magnitude is preserved; missing parts default to 0.

Axis3DComposite

3D axis composite — combines three float axis bindings (x/y/z) into a UnityEngine.Vector3. Analog magnitude is preserved; missing parts default to 0.

CompositeAttribute

Attribute to mark a class as a composite binding type. The composite name is used to identify the composite in binding configurations.

CompositeManager

Manages all composite binding types in the system. Automatically discovers and registers composites marked with [Composite] attribute.

LookRotationComposite

Look-rotation composite — accumulates a Vector2 delta (e.g. mouse movement) into yaw/pitch and outputs a UnityEngine.Quaternion. Designed for mouse-look camera control. Pitch is clamped to avoid gimbal lock; yaw is wrapped to avoid float overflow.

OneModifierComposite

One-modifier composite — combines a modifier binding and a main binding; outputs true only when both are pressed simultaneously.

QuaternionComposite

Quaternion composite — combines three float axis bindings (x/y/z Euler angles in degrees) into a UnityEngine.Quaternion.

TwoModifiersComposite

Two-modifiers composite — combines two modifier bindings and a main binding; outputs true only when all three are pressed simultaneously.

Vector2DComposite

2D vector composite — combines four boolean directional bindings (up/down/left/right) into a normalized UnityEngine.Vector2.

Vector3DComposite

3D vector composite — combines six boolean directional bindings (up/down/left/right/forward/back) into a normalized UnityEngine.Vector3.

Interfaces

ICompositeValue

Base interface for all composite binding types. Composite bindings combine multiple input values into a single output value.
