Class LicenseManager

Namespace
Votanic.VXR2.License
Assembly
Votanic.VXR2.License.dll

Manages VXR2 runtime license validation. All public properties automatically call the relevant initialiser on first access — explicit calls to InitSdk() or InitPlayer() are optional.

SDK license (SdkLicenseType, HasSdkLicense) is available immediately after InitSdk() returns. Player license (HasPlayerLicense) is set asynchronously — poll IsPlayerInitialized until true before reading it.

Methods

InitPlayer()

Begins player license validation on a background thread. Safe to call from any thread. Poll IsPlayerInitialized to know when validation has completed. Safe to call multiple times — subsequent calls are ignored once the background thread has started.

public static void InitPlayer()

InitSdk()

Reads the SDK license synchronously on the calling (main) thread. Must be called from the Unity main thread. Safe to call multiple times — subsequent calls are ignored once initialized.
