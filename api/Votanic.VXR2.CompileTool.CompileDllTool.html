Class CompileDllTool

Namespace
Votanic.VXR2.CompileTool
Assembly
VotanicXR.Editor.dll

Editor utility for compiling VotanicXR2 DLLs. Access via Tools > Compile DLL. Compiled DLLs go to BuildOutput/PlayerDlls/.

To control which DLLs are included: edit VxrCompileAssemblies (what gets compiled). Editor DLLs are listed separately in EditorAssemblies — they are always copied as-is.

ExportUnityPackage()

Stages the obfuscated DLLs from BuildOutput/ObfuscatedDlls/ alongside all other Votanic assets, then exports the result as a .unitypackage. Source .cs files and assembly definitions from the VXR2 SDK are excluded; third-party plugins and all non-code assets are included as-is.

[MenuItem("Tools/Build Package/Export VotanicXR2 .unitypackage")]
public static void ExportUnityPackage()

ExportUnityPackage(string)

Exports Assets/Votanic as a .unitypackage to the given path.

  1. Copy obfuscated DLLs into VXR2/Plugins/ and VXR2/Plugins/Editor/.
  2. Move all .cs and .asmdef source files out of VXR2/ to a temp folder.
  3. Refresh the asset database and export Assets/Votanic.
  4. Restore source files and remove injected DLLs (always runs in finally).
