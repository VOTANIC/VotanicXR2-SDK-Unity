Namespace Votanic.VXR2.CompileTool

Classes

CompileDllTool

Editor utility for compiling VotanicXR2 DLLs. Access via Tools > Compile DLL. Compiled DLLs go to BuildOutput/PlayerDlls/.

To control which DLLs are included: edit VxrCompileAssemblies (what gets compiled). Editor DLLs are listed separately in EditorAssemblies — they are always copied as-is.

RemoveSourceFilesTool

Removes all .cs source files from Assets/Votanic/VXR2/ together with their .meta files, then cleans up any directories left empty.

ScriptGuidRemapTool

Remaps MonoBehaviour script references in scene and prefab files from source .cs GUIDs to the equivalent classes inside compiled DLLs.

  1. Run Compile All VXR2 + Obfuscate (Release) to build DLLs into BuildOutput/PlayerDlls/.
  2. Run Remap Script GUIDs to DLLs — injects DLLs, remaps all scenes and prefabs, leaves DLLs in project.
  3. Run Remove Source Files Covered by DLLs to clean up source files.
VXR2WorkflowTool

Step-by-step workflow for packaging VotanicXR2 source assemblies into obfuscated DLLs and remapping all scene and prefab script references to point at the compiled DLLs. Access via Tools > VXR2 Workflow.

  1. Step 1 — Compile all VXR2 assemblies into BuildOutput/PlayerDlls/.
  2. Manual — Run Crypto Obfuscator; place obfuscated output into BuildOutput/ObfuscatedDlls/ (runtime) and BuildOutput/ObfuscatedDlls/Editor/ (editor).
  3. Step 2 — Verify all expected obfuscated DLLs are present.
  4. Step 3 — Move source out of the way, inject DLLs, remap all scene/prefab script references.
  5. Step 4 — Permanently delete the source files from the temp backup.
