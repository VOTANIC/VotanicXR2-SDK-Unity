AxisDeadzoneProcessor

Per-axis deadzone filter for Axis, Vector2, and Vector3 inputs. Each component is processed independently so a joystick can behave like a D-pad. Parameters: inner (threshold 0-1, default 0.125), outer (threshold 0-1, default 1.0)

ClampProcessor

CoordinateRemapProcessor

Remaps coordinate system axes to Unity's coordinate system (Right=+X, Up=+Y, Forward=+Z, Left-Handed). Define which source axes map to Unity's Right/Up/Forward to convert between coordinate systems.

Uses direct matrix transformation:

  • For Vector3: v' = C * v (where C is the conversion matrix)
  • For Quaternion: M' = C * M * C^T (similarity transform on rotation matrix)

The conversion matrix and its transpose are computed once on first use and cached for performance. The matrix is built from axis mappings where each column represents where Unity's axis comes from in the source coordinate system. Handedness is automatically handled via matrix determinant (det=-1 indicates handedness flip).

Parameters: right, up, forward (axis mappings like "+x", "-y", "+z", etc.)

RotateProcessor

Rotates values by specified angles. Supports 2D rotation by angle for Vector2, euler rotation for Vector3, and local-space euler offset for Quaternion. Parameters: angle (Vector2 rotation in degrees), or x, y, z euler angles (Vector3/Quaternion)

ScaleProcessor
