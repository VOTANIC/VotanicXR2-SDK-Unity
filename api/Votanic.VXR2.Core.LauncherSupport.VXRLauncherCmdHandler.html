Class VXRLauncherCmdHandler

Namespace
Votanic.VXR2.Core.LauncherSupport

Polls command folders created by VotanicXR Launcher beside the project root each frame. Registered launcher commands invoke their callback; unmapped commands raise OnUnmappedCommand.
