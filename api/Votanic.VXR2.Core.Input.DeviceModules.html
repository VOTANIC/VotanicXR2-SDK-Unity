Classes

ConstantDeviceModule

Device module that exposes constant identity values for each ValueType. Pair a constant path with binding processors (offset, rotate, invert) to produce any desired value. Supports path format: <Constant>/False|True|Axis|Vector2|Vector3|Quaternion. Examples:

  • <Constant>/True
  • <Constant>/Axis with processor offset(value=0.5)
  • <Constant>/Vector3 with processor offset(x=0,y=1,z=0)
  • <Constant>/Quaternion with processor rotate(x=0,y=90,z=0)
DeviceManager
