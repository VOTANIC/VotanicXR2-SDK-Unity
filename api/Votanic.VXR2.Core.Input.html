VXRInputManager

Input Manager for VXR framework. Handles input action mapping, device modules, interactions, processors, and event dispatching. Support 5 input types: bool, axis (a.k.a. float), Vector2, Vector3, Quaternion. Supports composite bindings and control schemes. Records action values of current and previous frames for querying.

XInputManager

Static manager for XInput controller access with background input support. Provides direct access to Xbox controllers via native Windows XInput API.
