Class VXRHapticManager

Namespace
Votanic.VXR2.Haptics

Manages haptic feedback for common controllers used by VXR Input Manager.
Support xInput gamepads and VR controllers.

Sends a haptic impulse to an XInput gamepad using the same amplitude for both motors. Any active haptic on the same controller index is stopped before the new impulse starts.
