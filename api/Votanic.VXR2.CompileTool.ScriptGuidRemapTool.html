Class ScriptGuidRemapTool

Namespace
Votanic.VXR2.CompileTool
Assembly
VotanicXR.Editor.dll

Remaps MonoBehaviour script references in scene and prefab files from source .cs GUIDs to the equivalent classes inside compiled DLLs.

  1. Run Compile All VXR2 + Obfuscate (Release) to build DLLs into BuildOutput/PlayerDlls/.
  2. Run Remap Script GUIDs to DLLs — injects DLLs, remaps all scenes and prefabs, leaves DLLs in project.
  3. Run Remove Source Files Covered by DLLs to clean up source files.

RemapScriptGuidsToDlls()

Injects obfuscated DLLs into Assets/Votanic/VXR2/Plugins/, then remaps all .unity and .prefab files under Assets/ to reference the DLL classes instead of the source .cs scripts.

  1. Collect source script GUIDs from VXR2/.
  2. Copy obfuscated DLLs into VXR2/Plugins/ and refresh the asset database.
  3. Query each DLL sub-asset to get its Unity-assigned fileID per class.
  4. Rewrite all .unity and .prefab files with the new GUID/fileID pairs.
