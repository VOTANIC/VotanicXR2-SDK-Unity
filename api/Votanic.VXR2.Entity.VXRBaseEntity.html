Class VXRBaseEntity

Namespace
Votanic.VXR2.Entity

Base class for XR entities that manages tracking, positioning, and rotation within the VotanicXR system.

VXRBaseEntity provides core functionality for entities that can be tracked in XR space, including:

  • Tracking state management (IsTracking, Position, Rotation)
  • Input binding through action bindings
  • Lost tracking behavior handling (Stay, Default, CustomLocation)
  • Entity lifecycle management (Awake, Enable, Disable, Destroy)
  • Centralized entity registry for bulk updates

Derived classes should override Setup() to customize initialization and the input action event methods (IsTrackedInputActionEvent, PositionInputActionEvent, RotationInputActionEvent) to handle specific tracking data.

The entity maintains both raw tracking data and applies transformations based on the current tracking mode and lost tracking configuration from entityData.
