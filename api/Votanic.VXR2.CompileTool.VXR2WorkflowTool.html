Namespace

Step-by-step workflow for packaging VotanicXR2 source assemblies into obfuscated DLLs and remapping all scene and prefab script references to point at the compiled DLLs. Access via Tools > VXR2 Workflow.

  1. Step 1 — Compile all VXR2 assemblies into BuildOutput/PlayerDlls/.
  2. Manual — Run Crypto Obfuscator; place obfuscated output into BuildOutput/ObfuscatedDlls/ (runtime) and BuildOutput/ObfuscatedDlls/Editor/ (editor).
  3. Step 2 — Verify all expected obfuscated DLLs are present.
  4. Step 3 — Move source out of the way, inject DLLs, remap all scene/prefab script references.
  5. Step 4 — Permanently delete the source files from the temp backup.

Step1_CompileDlls()

Compiles all VXR2 runtime assemblies for Windows x64 (Release) and copies editor DLLs from Library/ScriptAssemblies/ into BuildOutput/PlayerDlls/. Opens the output folder in Explorer when complete, then instructs you to run Crypto Obfuscator.

[MenuItem("Tools/VXR2 Workflow/Step 1 - Compile DLLs")]
public static void Step1_CompileDlls()

Step2_VerifyObfuscatedDlls()

Verifies that all expected obfuscated DLLs are present in BuildOutput/ObfuscatedDlls/ (runtime) and BuildOutput/ObfuscatedDlls/Editor/ (editor). No files are modified; this is an informational check only.

[MenuItem("Tools/VXR2 Workflow/Step 2 - Verify Obfuscated DLLs")]
public static void Step2_VerifyObfuscatedDlls()

Step3a_PrepareAndInjectDlls()

Collects source script GUIDs, moves all .asmdef and .cs source files to a temp backup folder, and injects the obfuscated DLLs into Assets/Votanic/VXR2/Plugins/.

Moving source files before DLL injection prevents duplicate-type compiler errors that occur when both .cs source and a DLL define the same class simultaneously. The collected GUID map is stored in SessionState so it survives the Unity domain reload that follows DLL injection. After Unity finishes reloading, run Step 3b. 

[MenuItem("Tools/VXR2 Workflow/Step 3a - Collect GUIDs and Inject DLLs")]
public static void Step3a_PrepareAndInjectDlls()

Step3b_RemapReferences()

Reads the source GUID map saved by Step 3a from SessionState, queries the already-imported DLL sub-assets for their Unity-assigned fileIDs, and rewrites every m_Script reference in all .unity and .prefab files under Assets/.

Run this step only after Unity has finished reloading assemblies following Step 3a. The DLL sub-assets are fully queryable only after the domain reload completes.

[MenuItem("Tools/VXR2 Workflow/Step 3b - Remap Script References")]
public static void Step3b_RemapReferences()

Step4_RemoveSourceFiles()

Permanently removes all source .cs and .asmdef files. Deletes the temp backup folder created by Step 3, removes any remaining .asmdef or .cs files still present under Assets/Votanic/VXR2/, and cleans up directories left empty as a result.

This action cannot be undone. Run only after verifying Step 3 was successful.

[MenuItem("Tools/VXR2 Workflow/Step 4 - Remove Source Files")]
public static void Step4_RemoveSourceFiles()
