RequestTeleport()

Attempts to queue a request to teleport to this anchor. This method can be called from script to initiate teleportation manually rather than relying on the interaction system to initiate teleportation. May not succeed in teleporting if the anchor Transform is destroyed or there is no UnityEngine.XR.Interaction.Toolkit.Locomotion.Teleportation.TeleportationProvider.

public void RequestTeleport()

Remarks

Due to script execution order of the UnityEngine.XR.Interaction.Toolkit.Locomotion.Teleportation.TeleportationProvider, depending on when this method is called, teleportation of the XR Origin may not occur until the next frame.
