Namespace Votanic.VXR2.Core

Classes

VXRCamera

Manages XR camera rendering.

The camera must be initialized through Votanic.VXR2.Core.VXRCamera.SetupXRCamera(Transform,Transform,XRCameraData,Votanic.VXR2.Core.VXRScreen,Viewport,RenderTexture,Rect) and is automatically destroyed if instantiated directly without proper initialization.

VXRObjectManager

Creates and tracks XR players, cameras, displays, and entities from the loaded config.

VXRSDKManager

Entry point for the vXR2 runtime. Loads config, initializes XR and input, then instantiates XR objects.

VXRScreen

Manages screen reference and editor preview.

Handles initialization of screen meshes (quad, static mesh, or dome types), world-space canvas rendering, and proximity warning visualization. Supports editor preview rendering and tracks nearby entities for proximity-based shader effects.

XRDisplay

Manages UI related aspect of the displays and viewports.

Allows adding UI elements to individual viewports.
