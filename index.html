VotanicXR2 Documentation

VotanicXR2 is a Unity toolkit for XR apps that run on HMDs and Votanic CAVE / dome systems. It extends Unity XR Interaction Toolkit (XRI) rather than replacing it. Core components — such as interactables, interactors, and locomotion providers — remain native to XRI, while VotanicXR2 introduces input mapping, CAVE configurations, faders and additional APIs to control interactors and locomotion providers.
