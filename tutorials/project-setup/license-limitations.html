License Limitations

These limits apply to the built application only.
Using the SDK in the Unity Editor does not require a license.

The SDK license active in the Unity Editor is saved into the player build. That build follows the table below. An expired, missing, or unrecognized SDK license uses the Invalid / Unregistered column.

Activate a license in VotanicXR Suite > License Manager. The steps are in Getting Started.

A limited session closes the built application when its time runs out.

VotanicXR Player license

This license applies on the playing side — the machine that runs the built experience. It is separate from the SDK license saved in the build.

A playing machine without a VotanicXR Player license runs the experience at low visual quality.
