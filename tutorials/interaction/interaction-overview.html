Interaction Framework

This chapter introduces the interaction features provided by VotanicXR2. The VotanicXR2 Interaction is a high-level interaction system. It provides a framework that enables user to interact with virtual objects in the VR environment. The core of this system consists of a set of Interactor and Interactable components.

Use the table below to quickly jump to the specific technical details of the interaction system:

Topic Description
Default interactors Default interactors attached to the player entities that initiate interactions.
Configure interactor settings Configure interactors attached to hand controllers.
Using interactors How to implement custom behavior on existing interactors.
Interactables Objects in the scene designed to receive input, such as buttons or grabbable tools.
