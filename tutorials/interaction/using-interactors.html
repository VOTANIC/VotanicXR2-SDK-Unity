Using interactors

To customize behavior of existing interactors, VotanicXR2 allows developers to manually control interactors under player entities which is accessed through VXRPlayer.Players.First().RightController.ControllerHandler.

Interactor control API

The VXRHandControllerHandler class provides the following methods to control the interactors under player entities.

VXRHandControllerHandler Public Methods

Method Description
GetInteractors Returns a collection of all interactors registered to the entity.
GetInteractorByName Retrieves a specific interactor by its GameObject name. Returns null if not found.
IsInteractorActive Checks if an interactor is active by name or if a specific interactor instance is active. Returns false if the interactor is missing.
SetInteractorActive Enables or disables an interactor.
ResetInteractors Disables all interactors and clears the interaction group.
RegisterActiveInteractor Register an interactor that was not created from VXRHandControllerSetting.
UnregisterActiveInteractor Unregister an interactor previously added with RegisterActiveInteractor or created from settings.

Code example: Press button to cycle through interactors

This example demonstrates how to implement cycling through a bunch of interactors when you press a button.

using System.Collections;
using System.Collections.Generic;
using System.Linq;
using System.Reflection;
using UnityEngine;
using UnityEngine.XR.Interaction.Toolkit.Interactors;
using Votanic.VXR2.Core;
using Votanic.VXR2.Core.Input;
using Votanic.VXR2.Core.Player;

namespace Votanic.VXR2.Sample
{
    /// <summary>
    /// Cycles the right-hand interactors, including one registered at runtime outside of
    /// <see cref="VXRHandControllerSetting"/>.
    /// Assign <see cref="sampleInteractor"/> in the inspector (a scene object with XRBaseInteractor).
    /// </summary>
    public class InteractorControl : MonoBehaviour
    {
        private readonly string triggerActionName = "NextInteractor";

        [SerializeField]
        [Tooltip("Optional interactor that is not listed in the hand controller setting. Registered at runtime onto the right controller.")]
        private XRBaseInteractor sampleInteractor;

        private VXRActionBinding<bool> _buttonInput;
        private List<XRBaseInteractor> interactors;
        private int index = -1;
        private VXRHandControllerHandler controllerHandler;
        private bool sampleInteractorRegistered;

        IEnumerator Start()
        {
            yield return new WaitUntil(() => VXRObjectManager.Instance.Initialized);
            _buttonInput = new VXRActionBinding<bool>(triggerActionName, ButtonAction);
            controllerHandler = VXRPlayer.Players.First().RightController.ControllerHandler; // Access controller handler of current player

            if (sampleInteractor != null)
            {
                controllerHandler.RegisterActiveInteractor(sampleInteractor, true);
                sampleInteractorRegistered = true;
            }

            interactors = controllerHandler.GetInteractors().ToList(); // Get list of interactor attached to the controller
            controllerHandler.ResetInteractors();
            MoveToNextInteractor();
        }

        private void OnEnable()
        {
            if (_buttonInput != null) _buttonInput.Bound = true;
        }
        private void OnDisable()
        {
            if (_buttonInput != null) _buttonInput.Bound = false;
        }
        private void OnDestroy()
        {
            if (sampleInteractorRegistered && controllerHandler != null && sampleInteractor != null)
            {
                controllerHandler.UnregisterActiveInteractor(sampleInteractor);
                sampleInteractorRegistered = false;
            }
            if (_buttonInput != null) _buttonInput.Dispose();
        }

        private void ButtonAction(bool value)
        {
            if (value) MoveToNextInteractor();
        }

        private void MoveToNextInteractor()
        {
            if (interactors == null || interactors.Count == 0) return;
            index++;
            index %= interactors.Count;
            controllerHandler.ResetInteractors();
            controllerHandler.SetInteractorActive(interactors[index], true);
        }
    }
}
