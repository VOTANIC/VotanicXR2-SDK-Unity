Locomotion System

The VotanicXR2 locomotion system offers a flexible framework for moving users within a VR environment. This system includes default locomotion providers and allows you to customize locomotion behaviors to suit your project’s needs. Refer to locomotion types to learn more about locomotion designs in VR.
