Reserved Action Names

Warning

These action names are reserved for the default action map. Do not reuse them as an action name in the Action Map Editor, or as the string passed to VXRActionBinding<T>. The input system matches action names by the exact string, so a custom action or binding that reuses one of these names shares callbacks with the built-in action.

The reserved strings below are the action names stored in the default action map. It is advised to prefix your own actions so the name cannot collide with a reserved name:

private readonly string actionName = "Movement"; // Collide with reserved name
private readonly string actionName = "Car_Movement"; // Add prefix, so it doesn't collide with reserved name
